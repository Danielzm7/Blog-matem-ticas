Zona docente

Mira cómo van los perfiles de este dispositivo, descarga el reporte y arma listas de juegos para compartir con el grupo.

Importante: los datos de progreso viven solo en el navegador de este dispositivo y no se envían a ningún servidor. Si se borra la memoria (caché) del navegador, se eliminan. No se guardan nombres reales ni datos sensibles: pide a los niños usar un apodo. El PIN solo evita que un niño abra esta pantalla por error; no es una medida de seguridad fuerte.
